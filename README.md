## ⚙️ What I Run Today

The GenAI platform at Evolui, designed, built and operated hands-on:

- 🧠 **Multi-agent architectures** with LangGraph, LangChain and **MCP servers**: tool calling, structured outputs, memory, context management and model fallback
- 🔀 **Multi-model routing** across Anthropic, OpenAI, Gemini and **AWS Bedrock/SageMaker**, tuned for latency, cost and resilience
- 📚 **RAG pipelines** on RDS + **PgVector**, with S3 for documents and DynamoDB for agent state
- ☁️ Containers on **ECS/EKS** and serverless on **Lambda + API Gateway**
- 🧪 **SDLC agents**: automatic generation, maintenance and validation of unit tests, AI-assisted code review, integrations with project-management tools

## 📐 Production-Grade AI

The part most demos skip, and where I spend most of my time:

- 📈 **LLMOps**: tracing, structured logs, prompt versioning, continuous monitoring of cost, latency and quality
- ✅ **Evaluation**: golden datasets, prompt regression tests, LLM-as-judge, RAG and agent evals, failure analysis, so models and prompts evolve **without regressions**
- 🛡️ **AI security & governance**: prompt-injection mitigation, data-leak prevention, access control, autonomy limits
- 🙋 **Human-in-the-loop** approval for every critical action an agent can take
